Часть 1. Случайные величины и их законы распределения

1.1. Дискретная случайная величина: способ задания, математическое ожидание, дисперсия, функция распределения

Случайная величина — величина, которая в результате опыта со случайным исходом принимает то или иное значение, причём заранее неизвестно, какое именно. Дискретной называется случайная величина, множество возможных значений которой конечно или счётно, то есть значения можно перечислить.

Способ задания — закон (ряд) распределения

Законом распределения называется любое правило (таблица, функция, график), устанавливающее связь между возможными значениями случайной величины и вероятностями их появления. Для ДСВ закон распределения обычно задаётся рядом распределения — таблицей:

Xx1x2…xk…xn
Pp1p2…pk…pn

где pk = P(X = xk). События {X = xk} несовместны и образуют полную группу, поэтому выполняется условие нормировки:

p1 + p2 + … + pn = ∑ pk = 1

Графически ряд распределения изображают многоугольником распределения — ломаной, соединяющей точки (xk, pk).

Функция распределения

Функцией распределения случайной величины X называется вероятность того, что X примет значение, меньшее x:

F(x) = P(X < x) = ∑x_{i < x} pi

Для ДСВ F(x) — разрывная ступенчатая функция: скачки происходят в точках xk и равны pk; сумма всех скачков равна 1. Например, при x1 < x ≤ x2 F(x) = p1, при x2 < x ≤ x3 F(x) = p1 + p2 и т.д.

Свойства функции распределения:

  • 0 ≤ F(x) ≤ 1;
  • F(x) неубывающая: если x2 > x1, то F(x2) ≥ F(x1);
  • F(−∞) = 0, F(+∞) = 1;
  • P(a ≤ X < b) = F(b) − F(a);
  • F(x) непрерывна слева.

Математическое ожидание

Математическое ожидание — среднее значение случайной величины (центр распределения):

M(X) = ∑ xk pk = x1p1 + x2p2 + … + xnpn

Свойства: M(C) = C; M(CX) = C·M(X); M(X + Y) = M(X) + M(Y); для независимых X и Y M(XY) = M(X)·M(Y).

Дисперсия

Дисперсия — математическое ожидание квадрата отклонения случайной величины от её математического ожидания (мера рассеяния). Отклонение X* = X − M(X) называется центрированной случайной величиной, M(X*) = 0.

D(X) = M[(X − M(X))2] = ∑ (xk − M)2 pk

Раскрывая квадрат, получаем более удобную формулу:

D(X) = ∑ xk2 pk − M2 = M(X2) − [M(X)]2

Среднее квадратическое отклонение: σ(X) = √D(X). Свойства дисперсии: D(X) ≥ 0; D(C) = 0; D(CX) = C2D(X); D(X + C) = D(X); для независимых X и Y D(X ± Y) = D(X) + D(Y).

Пример

X12345
P0,20,20,20,20,2

M = 0,2·(1 + 2 + 3 + 4 + 5) = 3, D = 0,2·(1 + 4 + 9 + 16 + 25) − 32 = 11 − 9 = 2

1.2. Непрерывная случайная величина: плотность распределения

Непрерывной называется случайная величина, возможные значения которой непрерывно заполняют некоторый промежуток (конечный или бесконечный), а функция распределения F(x) непрерывна и (кусочно) дифференцируема. Для НСВ вероятность любого отдельного значения равна нулю: P(X = x) = 0, поэтому ряд распределения построить нельзя и закон распределения задают плотностью.

Плотностью распределения (дифференциальной функцией распределения) называется производная функции распределения:

f(x) = F′(x) = limΔx→0 P(x ≤ X < x + Δx) / Δx

Смысл: f(x)·dx — вероятность попадания X в элементарный интервал (x, x + dx). График f(x) называется кривой распределения.

Свойства плотности

  • f(x) ≥ 0 (так как F(x) неубывающая);
  • условие нормировки: ∫−∞+∞ f(x) dx = 1 (площадь под кривой распределения равна 1);
  • P(a < X < b) = ∫ab f(x) dx = F(b) − F(a);
  • F(x) = ∫−∞x f(t) dt.

Если X задана на интервале (a, b), то f(x) > 0 при x ∈ (a, b), f(x) = 0 вне его и ∫ab f(x) dx = 1.

Числовые характеристики через плотность

M(X) = ∫−∞+∞ x f(x) dx

D(X) = ∫−∞+∞ (x − M)2 f(x) dx = ∫−∞+∞ x2 f(x) dx − M2

Пример

f(x) = 4x3 на (0, 1). Проверка нормировки: ∫01 4x3 dx = x4|01 = 1.

M = ∫01 4x4 dx = 45, D = ∫01 4x5 dx − (45)2 = 23 − 1625 = 275

1.3. Непрерывная случайная величина: функция распределения

Функция распределения (интегральная функция) непрерывной случайной величины определяется так же, как для дискретной: F(x) = P(X < x). Отличие в том, что для НСВ F(x) непрерывна на всей числовой оси (а не ступенчата).

Связь с плотностью:

F(x) = ∫−∞x f(t) dt, f(x) = F′(x)

Для величины, заданной на (a, b):

F(x) = 0 при x ≤ a; F(x) = ∫ax f(t) dt при a < x < b; F(x) = 1 при x ≥ b

Свойства

  • 0 ≤ F(x) ≤ 1;
  • F(x) — неубывающая функция; на интервале, где f(x) > 0, — строго возрастающая (поэтому имеет обратную функцию x = F−1(y), что используется при моделировании);
  • F(−∞) = 0, F(+∞) = 1;
  • F(x) непрерывна, следовательно P(X = x) = 0;
  • P(a < X < b) = P(a ≤ X ≤ b) = P(a ≤ X < b) = F(b) − F(a).

Пример

Для f(x) = 4x3 на (0, 1): F(x) = 0 при x ≤ 0; F(x) = x4 при 0 < x < 1; F(x) = 1 при x ≥ 1. Тогда P(0,5 < X < 1) = 1 − 0,54 = 0,9375.

1.4. Равномерное распределение

Непрерывная случайная величина X распределена равномерно на отрезке [a, b], если её плотность на этом отрезке постоянна, а вне его равна нулю. Обозначение: X ~ R[a, b].

Плотность распределения

f(x) = 1b − a при x ∈ [a, b]; f(x) = 0 при x ∉ [a, b]

Константа 1b − a получается из условия нормировки: площадь прямоугольника с основанием (b − a) должна быть равна 1.

Функция распределения

F(x) = 0 при x < a; F(x) = x − ab − a при a ≤ x ≤ b; F(x) = 1 при x > b

Математическое ожидание

M(X) = ∫ab xb − a dx = b2 − a22(b − a) = a + b2

Дисперсия

M(X2) = ∫ab x2b − a dx = a2 + ab + b23

D(X) = a2 + ab + b23 − (a + b)24 = (b − a)212, σ = b − a2√3

Вероятность попадания в интервал (α, β) ⊂ [a, b] пропорциональна его длине: P(α < X < β) = β − αb − a.

Частный случай R[0, 1]: f = 1, F(x) = x, M = 12, D = 112. Именно эта величина является базовой при моделировании (её дают функции RANDOM, RAND и т.п.).

1.5. Показательное (экспоненциальное) распределение

Непрерывная случайная величина X имеет показательное распределение с параметром λ > 0, если её плотность:

Плотность распределения

f(x) = λ e−λx при x ≥ 0; f(x) = 0 при x < 0

Функция распределения

F(x) = ∫0x λ e−λt dt = 1 − e−λx при x ≥ 0; F(x) = 0 при x < 0

Математическое ожидание и дисперсия

Интегрированием по частям:

M(X) = ∫0∞ x λ e−λx dx = 1λ

M(X2) = ∫0∞ x2 λ e−λx dx = 2λ2, D(X) = 2λ2 − 1λ2 = 1λ2

σ(X) = 1λ = M(X)

Для показательного распределения математическое ожидание равно среднему квадратическому отклонению.

Дополнительные свойства

  • P(a < X < b) = e−λa − e−λb.
  • Отсутствие последействия («отсутствие памяти»): P(X ≥ t + τ | X ≥ t) = P(X ≥ τ) = e−λτ.
  • Применение: время между событиями простейшего (пуассоновского) потока с интенсивностью λ, время обслуживания в системах массового обслуживания, время безотказной работы (функция надёжности R(t) = e−λt).

1.6. Нормальное распределение

Непрерывная случайная величина X распределена нормально (по закону Гаусса) с параметрами a и σ > 0, если её плотность:

Плотность распределения

f(x) = 1σ√(2π) · e−(x − a)²/(2σ²), −∞ < x < +∞

Обозначение: X ~ N(a, σ). Свойства кривой нормального распределения (кривой Гаусса):

  • определена на всей оси, f(x) > 0, ось Ox — горизонтальная асимптота;
  • симметрична относительно прямой x = a;
  • максимум в точке x = a, равный 1σ√(2π);
  • точки перегиба x = a ± σ;
  • изменение a сдвигает кривую вдоль оси Ox без изменения формы; увеличение σ делает кривую ниже и шире (площадь остаётся равной 1).

Числовые характеристики

M(X) = a, D(X) = σ2, σ(X) = σ

Таким образом, параметры нормального закона имеют прямой смысл: a — математическое ожидание, σ — среднее квадратическое отклонение. Для нормального распределения мода и медиана тоже равны a.

Стандартное нормальное распределение

При a = 0, σ = 1 получаем N(0, 1) с плотностью φ(x) = (1√(2π)) e−x²/2. Любая X ~ N(a, σ) приводится к стандартной заменой Z = X − aσ.

Функция распределения

F(x) = 1σ√(2π) ∫−∞x e−(t − a)²/(2σ²) dt = 12 + Φ(x − aσ)

где Φ(x) — функция Лапласа (табулирована):

Φ(x) = 1√(2π) ∫0x e−t²/2 dt

Свойства Φ(x): нечётная, Φ(−x) = −Φ(x); Φ(0) = 0; Φ(+∞) = 0,5; при x > 5 Φ(x) ≈ 0,5. Интеграл не выражается через элементарные функции.

Вероятность попадания в интервал

P(α < X < β) = Φ(β − aσ) − Φ(α − aσ)

P(|X − a| < δ) = 2Φ(δσ)

Правило трёх сигм

δσ2σ3σ
P(|X − a| < δ)0,68270,95450,9973

Практически все значения нормально распределённой величины (99,73 %) лежат в интервале (a − 3σ, a + 3σ).

Значение нормального закона объясняет центральная предельная теорема: сумма большого числа независимых случайных величин с конечными дисперсиями (каждая из которых вносит малый вклад) распределена приближённо нормально.

Часть 2. Моделирование случайных величин

При моделировании на ЭВМ вместо истинно случайных чисел используются псевдослучайные — числа, получаемые по детерминированному алгоритму, но по своим статистическим свойствам близкие к случайным. Базисом для моделирования служит псевдослучайная величина R, равномерно распределённая на (0, 1) (функции Random, RAND(), RANDOM()). Генератор инициализируется один раз (например, Randomize по системному таймеру); повторная инициализация внутри одной последовательности нарушает равномерность.

2.1. Моделирование дискретной случайной величины (алгоритм)

Пусть ДСВ X задана рядом распределения x1, …, xn с вероятностями p1, …, pn. Используется метод обратной функции.

Идея метода

Отрезок [0, 1] разбивается на частичные отрезки Δ1, Δ2, …, Δn длиной p1, p2, …, pn (так как ∑pk = 1, они покрывают весь отрезок). Границы отрезков — накопленные вероятности, то есть значения функции распределения:

Δ1 = [0; p1], Δk = (p1 + … + pk−1; p1 + … + pk], k ≥ 2

Если псевдослучайное число r попало в Δk, то X принимает значение xk. Так как R равномерна, P(r ∈ Δk) = длина Δk = pk, что и требуется. Название метода: на оси ординат графика F(x) разыгрывается r, а по ней находится абсцисса x = F−1(r).

Алгоритм

  • Ввести значения xk, вероятности pk, объём выборки N.
  • Вычислить накопленные вероятности: S0 = 0, Sk = Sk−1 + pk, k = 1, …, n (Sn = 1).
  • Инициализировать генератор (один раз).
  • Для i = 1, …, N: получить r = RANDOM; найти наименьшее k, для которого r ≤ Sk; положить Xi = xk.
  • Вывести первые q значений выборки.
  • Вычислить точные значения M = ∑xkpk, D = ∑xk2pk − M2.
  • Вычислить оценки m и d по выборке (см. ниже) и сравнить с точными.

Статистические оценки

Несмещённая оценка математического ожидания (выборочное среднее):

m = (1N) ∑i=1N xi

Оценка g = (1N)∑xi2 − m2 является смещённой: M(g) = N − 1N · D, поскольку используется не точное M, а его оценка m. Несмещённая оценка дисперсии:

d = (1N − 1) ∑i=1N xi2 − NN − 1 · m2 = (1N − 1) ∑ (xi − m)2

Замечание: m нужно вычислить полностью (по всем N значениям) до вычисления d, поэтому оценки нельзя считать в одном цикле с накоплением m.

С ростом N оценки сходятся к точным значениям (закон больших чисел); погрешность оценки среднего порядка σ√N.

2.2. Моделирование непрерывной случайной величины

Пусть НСВ X задана на (a, b) плотностью f(x) > 0 и функцией распределения F(x). Применяется метод обратной функции.

Обоснование

Так как f(x) > 0 на (a, b), функция y = F(x) строго возрастает и имеет однозначную обратную x = G(y) = F−1(y), определённую на (0, 1) со значениями в (a, b). Пусть R ~ R(0, 1) и ξ = G(R). Тогда неравенства c < ξ < d и F(c) < R < F(d) равносильны, поэтому:

P(c < ξ < d) = P(F(c) < R < F(d)) = F(d) − F(c)

Следовательно, F(x) является функцией распределения ξ, то есть ξ совпадает по распределению с X.

Алгоритм

  • По плотности найти функцию распределения: F(x) = ∫ax f(t) dt.
  • Решить уравнение F(x) = r относительно x, получить явную формулу x = F−1(r).
  • Для i = 1, …, N: получить ri = RANDOM, вычислить xi = F−1(ri).
  • Вычислить точные M = ∫x f(x)dx, D = ∫x2f(x)dx − M2 и оценки m, d по тем же формулам, что и для ДСВ; сравнить.

Пример

f(x) = 4x3 на (0, 1): F(x) = x4; x4 = r ⇒ x = r1/4 = ⁴√r. Точные значения: M = 0,8, D = 275 ≈ 0,0267.

Ещё пример: f(x) = sin x на (0, π2): F(x) = 1 − cos x ⇒ x = arccos(1 − r).

Ограничение метода: уравнение F(x) = r должно решаться явно. Если это невозможно (например, для нормального закона), используют другие методы — специальные преобразования, метод отбора (Неймана) и т.п.

2.3. Моделирование равномерного распределения

X ~ R[a, b]: F(x) = x − ab − a. По методу обратной функции решаем уравнение:

x − ab − a = r ⇒ x = a + (b − a)·r

Алгоритм: для i = 1, …, N получить ri = RANDOM и вычислить xi = a + (b − a)ri. Это линейное преобразование отрезка (0, 1) в (a, b).

Контроль: точные значения M = a + b2, D = (b − a)212 сравниваются с оценками m и d. Для проверки качества самого генератора RANDOM строят гистограмму значений ri (она должна быть близка к прямоугольной) и проверяют гипотезу о равномерности критерием Пирсона.

Пример: a = 2, b = 5, r = 0,4 ⇒ x = 2 + 3·0,4 = 3,2.

2.4. Моделирование показательного распределения

X имеет показательное распределение с параметром λ: F(x) = 1 − e−λx, x ≥ 0. Решаем уравнение F(x) = r:

1 − e−λx = r ⇒ e−λx = 1 − r ⇒ x = −(1λ)·ln(1 − r)

Так как величина 1 − R также равномерно распределена на (0, 1), формулу можно упростить:

x = −(1λ)·ln r

Алгоритм: для i = 1, …, N получить ri = RANDOM (при ri = 0 повторить розыгрыш, так как ln 0 не определён) и вычислить xi = −ln(ri)λ.

Контроль: M = 1λ, D = 1λ2. Применение: моделирование интервалов между заявками простейшего потока и времени обслуживания в системах массового обслуживания.

Пример: λ = 2, r = 0,3 ⇒ x = −ln 0,32 ≈ 1,2042 ≈ 0,602.

2.5. Моделирование нормального распределения

Для N(a, σ) функция распределения выражается через интеграл Лапласа и не обращается в элементарных функциях, поэтому метод обратной функции напрямую не применяется. Сначала моделируют стандартную величину Z ~ N(0, 1), затем выполняют преобразование:

X = a + σ·Z

Способ 1. На основе центральной предельной теоремы

Сумма n независимых Ri ~ R(0, 1) имеет M = n2, D = n12 и при большом n распределена приближённо нормально. Нормированная сумма:

Z = (∑i=1n ri − n2) / √(n12)

Обычно берут n = 12, тогда формула особенно проста:

Z = ∑i=112 ri − 6, X = a + σ(∑i=112 ri − 6)

Недостаток: значения Z ограничены отрезком [−6; 6], «хвосты» распределения воспроизводятся приближённо; на одно значение расходуется 12 случайных чисел.

Способ 2. Метод Бокса — Мюллера

По двум независимым r1, r2 ~ R(0, 1) получают две независимые стандартные нормальные величины (точный метод):

Z1 = √(−2 ln r1) · cos(2πr2), Z2 = √(−2 ln r1) · sin(2πr2)

Алгоритм

  • Ввести a, σ, N.
  • Для i = 1, …, N: получить нужное количество чисел RANDOM, вычислить zi одним из способов, затем xi = a + σzi.
  • Сравнить оценки m и d с точными M = a, D = σ2; проверить правило трёх сигм (доля значений в (a − 3σ, a + 3σ) ≈ 0,9973); построить гистограмму и проверить нормальность критерием Пирсона.

2.6. Гистограмма. Критерий согласия Пирсона

Гистограмма

Гистограмма — ступенчатая фигура, состоящая из прямоугольников, основаниями которых служат частичные интервалы длины h, а высоты равны nih (гистограмма частот) или wih = niNh (гистограмма относительных частот). Гистограмма относительных частот является статистическим аналогом (оценкой) плотности распределения; её площадь равна 1.

Построение гистограммы по выборке x1, …, xN:

  • Найти xmin, xmax и размах R = xmax − xmin.
  • Выбрать число интервалов k (например, по формуле Стёрджеса k ≈ 1 + 3,322 lg N или k ≈ √N) и шаг h = Rk.
  • Подсчитать ni — число значений, попавших в i-й интервал (∑ni = N).
  • Вычислить относительные частоты wi = niN и высоты wih.
  • Построить прямоугольники; для сравнения на тот же график нанести теоретическую плотность f(x).

Критерий согласия Пирсона (χ²)

Критерий согласия — правило проверки гипотезы о предполагаемом законе распределения. Проверяется нулевая гипотеза H0: «случайная величина X имеет функцию распределения F(x)» (например, нормальную, показательную, равномерную).

Порядок применения:

  • Разбить выборку объёма N на k интервалов, найти эмпирические частоты ni.
  • Если параметры закона неизвестны, оценить их по выборке (для нормального a ≈ m, σ ≈ √d; для показательного λ ≈ 1m).
  • Вычислить теоретические вероятности попадания в интервалы: pi = P(ai < X < bi) = F(bi) − F(ai) и теоретические частоты N·pi.
  • Вычислить наблюдаемое значение статистики:

χ²набл = ∑i=1k (ni − Npi)2Npi

  • Определить число степеней свободы ν = k − 1 − s, где s — число параметров, оценённых по выборке (нормальное — 2, показательное — 1; если параметры заданы заранее, s = 0).
  • По таблице найти критическое значение χ²кр(α; ν) для уровня значимости α (обычно 0,05).
  • Если χ²набл < χ²кр — нет оснований отвергнуть H0 (данные согласуются с законом); если χ²набл ≥ χ²кр — гипотеза отвергается.

Смысл: статистика χ² характеризует суммарное расхождение эмпирических и теоретических частот; при справедливости H0 и больших N она имеет распределение χ² с ν степенями свободы (теорема Пирсона).

Условия применимости: объём выборки N ≥ 50; в каждом интервале Npi ≥ 5 (малочисленные крайние интервалы объединяют с соседними, уменьшая k).

Применительно к моделированию: критерий Пирсона позволяет проверить, что смоделированная выборка (равномерная, показательная, нормальная) действительно подчиняется заданному закону, то есть что генератор и алгоритм моделирования работают правильно.
